# Titanic Survival Analysis

Exploratory data analysis and logistic regression on the Titanic dataset, 
identifying the key factors that influenced passenger survival.

## Overview

This project investigates patterns in a 900+ record dataset of Titanic 
passengers, using Python and R to explore the data and build a predictive 
model of survival outcomes.

## Methods

- **Exploratory Data Analysis (EDA):** cleaned and explored the dataset to 
  identify trends and relationships between passenger characteristics and 
  survival.
- **Logistic Regression:** modelled survival probability as a function of 
  categorical variables including gender, passenger class, and age.
- **Tools:** Python and R, developed in Google Colab.

## Key Findings

- Passenger gender and class were strong predictors of survival likelihood.
- Age contributed additional explanatory power alongside class and gender.
- The analysis highlights how demographic and socioeconomic factors shaped 
  survival outcomes during the disaster.
